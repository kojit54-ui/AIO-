## 班への指示（ラッコキーワードで「困りごとを探す人の目線」から集める）

目的：日本の中小製造業（一人親方〜30人規模の町工場など）が、AI検索に引用され、読んだ見込み客（発注する設計・購買担当、試作したい開発者、個人、求職者）に選ばれるブログ記事を書くための「製造業の知識表」を増やす。今回は「発注する人・困っている人が実際に検索する言葉」と「その言葉で上位に出るページ・Googleの『AIによる概要』に引用されているページ」から、読む人の疑問と、答えに入れるとよいことを集める。

### 道具（ラッコキーワードMCP。ToolSearch で `select:` 読み込み。ツール名は mcp__dc925b75-0a7d-4667-9074-220edbbe058c__ で始まる）
- question-search（1.5クレジット）：キーワードを含む「よくある質問」。limit 200〜300、filter.keyword.notIncludes で消費者向けのノイズを除く（例：車・バイク・塗装の板金修理、DIY、ネイル、歯科 など）。**10回まで**。
- headline（3クレジット）：検索上位20ページの見出し。発注者の疑問として多いものに使う。limit 10、h4 は false。**8回まで**。
- influx-aio（4.5クレジット）：指定ドメインのページが「AIによる概要」に引用されているキーワード、その回答本文、引用ページ。fields は ["keyword","aio.answerMarkdown","page"]、limit 20。filter.keyword.includes で発注者向けの語（費用、価格、相場、違い、選び方、注文、依頼、外注、納期、精度、公差、とは、注意 など）に絞る。**ページ送りは同じ条件なら1時間以内は無料**なので2〜5ページまで。担当ドメインは**合計8リクエストまで**（ページ送りは数えない）。
- 合計のクレジットは**90まで**。WebSearch は使わない（必要なら3回まで）。
- 大きな結果は自分の中で要点だけ読み、生データを長く書き写さない。

### 書き方
- 文章は写さない。とくに「AIによる概要」の本文は Google の文章なので、事実の要点だけを自分のやさしい日本語でまとめ直す。
- title 30字以内、summary 120字以内、articleIdea 40字以内。
- source.url は、ツールの結果に実際に出たページのURLだけ（AIOの引用ページ、見出し抽出の上位ページ）。source.title はそのページのタイトル、publisher はサイト名（分からなければドメイン）、date は分からなければ null。
- URL・数字・法律・調査結果を作らない。数字（費用・公差・日数など）は、引用ページやAIOの本文に書いてあるときだけ、「目安」「一例」と分かるように書く。
- summary の中に中小の会社名・個人名を書かない。大手（公開資料に名前が出ている会社）も、summary にはなるべく書かない。
- 1つの発行元（ドメイン）から8件まで。
- 消費者向け（車の板金修理、家庭のDIY など）や、製造業の発注・仕事と関係の薄いものは入れない。
- 重ねない：作業フォルダの existing_titles.txt・existing_urls.txt、同じフォルダの他の r*.json と、見出しも出典URLも重ねない（URLは同じでも中身が別の疑問ならよいが、1URLから3件まで）。

### 作るもの（kind）
- question：読む人の疑問と、その答えに入れるとよいこと。上位ページの見出しで共通して扱う点、AIOの回答で触れている点を「答えに入れるとよいこと：…」の形で。title は疑問の形（例「アルミ切削の費用はどう決まる？」）。
- buyer：発注する人の探し方・決め方・比べ方（何を見て頼み先を選ぶか、見積で何を出すか）。
- term：発注者がつまずく言葉のやさしい説明。
- pain：発注する人や作り手の悩み（「図面がなくて頼めない」「小ロットで断られる」など、質問文から読み取れる困りごと）。
- useFor は ["question_example","article_idea","writer_hint","shiori_tip"] から。question は question_example と article_idea を必ず含める。
- industries に使える業種（「、」区切り。「刃物・工具」のように「・」を含むものは1つの名前なので、そのまま書く）：切削加工、研削、放電加工、板金、プレス、溶接、製缶、樹脂成形、ゴム、金型、鋳造、鍛造、熱処理、表面処理、塗装、食品製造、化粧品OEM、印刷、パッケージ、印刷機械、木工、繊維、電子部品、基板実装、組立、装置、治具、3Dプリンタ、金属加工、機械部品、ばね・線材、ねじ・締結部品、歯車、パイプ加工、医療機器、半導体、自動車部品、航空宇宙、看板・サイン、ガラス・セラミック、化学・塗料・接着剤、建材・金物、刃物・工具、食品機械、産業機械、精密機器、紙加工、プラスチック加工品、酒・醸造。全業種なら ["all"]。

### 出力
JSON 配列を、指示されたファイル名で Bash（python）で書く。**80〜120件**。各要素：
`{"kind": "question"|"buyer"|"term"|"pain", "title": "...", "summary": "...", "industries": [...], "useFor": [...], "articleIdea": "（任意）", "source": {"title":"...","url":"https://...","publisher":"...","date": null}}`

書き終えたら python で JSON が読めること・長さの上限・重なりが無いことを確かめ、6行で報告する（何件・kind別の件数・使ったクレジットの合計・使った検索語とドメイン・弱いところ・おもしろかった発見1つ）。
