# UI：画面・文言・状態

## 共通ルール

- 専門用語を減らし、次の操作をひとつずつ示す。主導線のボタン文言は「今月の記事を書く」
- 本文16px以上、すべての入力欄にラベル、キーボードだけで操作可能、十分なコントラスト（WCAG AA相当）
- 色とロゴは仮置き
- 画面試作の段階では、生成結果は「サンプル（AIは未接続）」と画面上に明示する

## サービスの定義と言葉（2026-11-03）

- サービス全体の定義は docs/AIO.md「このサービスの定義」。ひとことは「AIに選ばれて、これから出会うお客様に選ばれる会社へ。」、いちばん大切なのはお客様に選ばれること
- 2つの段階は、どの画面でも同じ見た目で見せる：「🤖 AIに選ばれる」＝青の札（brand-soft）、「🤝 お客様に選ばれる」＝黄色の札（sun）。並べるときは矢印でつなぎ、お客様に選ばれる側に「いちばん大切」を添える（src/components/ChosenPath.tsx）
- ChosenPath を出す場所：ホーム（あいさつの下）、ログイン・招待の青い面、招待状、しおりの自己紹介。入口（/welcome）は「2つの「選ばれる」」の段と、AIに相談→紹介→記事を読んで問い合わせ、までの動き
- 質問の「なぜ聞くの？」は、材料の名前に続けて「AIに選ばれる」「お客様に選ばれる」の2行で理由を書く。AIOのチェックの結果と「こんなチェックをします」は、2つの段階に分けて並べる
- 30秒でためすの最後の「🔮 1年後、お客様がAIに相談したら…？」（src/app/try/FutureAnswer.tsx）：カレンダーが12か月めくれる→AIへの相談→会社名が出る答え→「1. AIに選ばれた」→記事を読む人の気持ち→「2. お客様に選ばれた」と紙吹雪。濃い色の面で、イメージだと明記
- ホームの「🏘️ AIの町すごろく」（src/components/TownBoard.tsx）：町の絵（真ん中に会社の看板の建物。空き地→小さなお店→町のお店→目立つビル→町のシンボル）と8マス（スタート＋7）。コマは🏠で、前に見たときより進んでいたら1マスずつ跳んで進み紙吹雪。AIに選ばれると建物の上にAIの星、お客様に選ばれるとお客様が入り口に来る
- 左上のロゴ（✎の四角）とサービス名は、ログイン前・ログイン後・新しい流れの試作で同じものにする

## 見た目と動き（2026-11-01 田村さんが案Bを選択）

- 入口（/welcome、2026-11-03）：ログインしていない人がトップを開くと出る。上から、見出し「AIに『この会社がいいよ』と紹介される会社に。」としおり（まわりに浮く札）→ AIに相談している画面のイメージ（見えたら自動で流れ、あなたの会社が紹介される）→ 1問クイズ「AIに紹介されやすいのはどっち？」（正解で紙吹雪）→ やることは3つ → スタンプ帳としおりが育つ（見えたら押される）→ こんな方のための → 最後の呼びかけ。紹介や売上は約束しない（「決めるのはAI」と書く）。料金は出さない
- 30秒でためす（/try、2026-11-03）：ログインなし。会社の名前・地域・仕事 → お客さんがAIに聞きそうな質問を見せる → 6つの質問に はい・少し・いいえ（材料ごと。答えるたびにしおりのひとことと +10pt）→ AIに紹介される準備度（点数が数えあがる輪、たまご〜エース級、足りない材料）→ 「最近うれしかった仕事」を1問 → 書いている演出 → 記事の書き出し（あなたの言葉に印、続きはぼかす、次にしおりが聞くこと）・紙吹雪・スタンプ → 続きを書く（ログイン）。書き出しは本物のAI（src/app/api/try、src/lib/tryoutAi.ts。AIを使えないときや回数を超えたときは見本に切り替え、しおりが理由を言う）。入力は保存しない。点数は「答えから出した目安」と書く
- しおりの自己紹介（/shiori、2026-11-03）：あいさつ、プロフィール帳、表情図鑑（押すとその顔で話す。15こ全部見ると紙吹雪）、できること、育ち方（Lv.1〜7）、しおりに聞いてみた（しおりは案内役のキャラクターで、裏でAIが動いていると正直に書く）
- 招待状（/invite/[token]、2026-11-03）：封筒（しおりの封ろう）→ 自動で開いて「ご招待状 〇〇様」、無料ご招待の札、コタムよりのひとこと、しおりのあいさつ、できること、同意してはじめる。管理画面（/admin/invitations）で宛名・ひとこと・無料の札を入れ、「招待状の見え方を確かめる」で確認（src/components/InviteLetter.tsx）
- 30秒でためすの見守り（/admin/trial、2026-11-03）：AIの動いている／止まっている とボタン、今日の回数・AIで作れた回数・今月の費用、予算の帯、2週間の回数、見本に切り替えた理由、上限の変更。招待と所属の管理から入る
- 30秒でためすの最後に「このブラウザに覚えておく」（任意）。ヒアリング（/prototype/hearing）の上に「30秒でためすで教えてくれたことを入れましょうか？」→ 入れる（どんなお仕事・地域・選ばれる理由に途中の答えとして）／使わない
- ログイン・招待（/login、/invite/[token]）：左（スマホは上）に青い面としおりのあいさつ（時間帯で変わる）と「入るとできること」、右に入力。メールを送ったら、飛ぶ封筒と「次にやること」3つ、届かないときの案内。招待は紙吹雪で迎える

- 会社プロフィールまたは指導メモが未登録なら「コタムが準備中です」と表示し、記事作成へ進ませない（コタムには初期設定へ案内）

### 会社の情報が無いとき（2026-11-02）

- S2 と /profile は「まず、会社のことを教えてください」（会社のことを教える → AIがまとめる → 確かめる）を出す。コタムの登録は待たない
- /profile に「会社のことを教える」の答えを直す・答えからまとめ直す
- テーマがコタムから届いていなければ、「自分でテーマを決める」と「しおりのおすすめから選ぶ」を出す
- ヒアリング（/prototype/hearing）：答えるたびに、しおり（考え中）が「なぜ聞くの？」を添えて深掘りの質問を出す（本物のデータではAIが答えを読んで聞く。1問につき4回まで、「この質問は飛ばす」で終われる）

## S3 質問に答える

- 4〜6問を1問ずつ表示。進捗（例：2／5）、戻る、下書き保存を常時表示
- 各質問に記入例と「まだ分からない」ボタン
- 質問例：
  1. お客様から何を相談されましたか
  2. 実際にはどう対応しましたか
  3. 結果はどうなりましたか（数値があれば）
  4. 注意点や、よくある誤解はありますか
  5. この記事を読んだ人にしてほしいこと（問い合わせ等）
- 回答が具体例に欠ける場合、生成前に追加質問を1〜2問出す
- 全問回答後「見出し案を作る」

## S4 記事を整える

PC：本文を主領域、右に補助領域（タブ：質問回答／指導方針／要確認箇所／コメント）。スマートフォン：上部タブで本文と補助領域を切り替え。

主領域：
- タイトル候補から選択、または直接編集
- 見出しと本文を編集
- 範囲を選んで「短くする」「伝わりやすくする」→ 変更案を差分表示 →「採用」「やめる」
- 「もう一度作る」は新しい版を作る（元の版は残る）
- 版の履歴から以前の版を復元

要確認箇所タブ：
- 数値・実績・価格・顧客名などを一覧表示。該当箇所へジャンプ
- 各項目に「確認した」「修正した」「削除した」。未確認が残っていれば確認依頼・書き出し時に件数を警告（止めはしない）

操作ボタン：
- 「AIOのチェックを実施」（2026-11-02、人の確認の代わり）。押す前に「こんなチェックをします」で13項目（AIOの9つの材料＋強みの根拠、数字・実績の確かさ、使ってほしくない言葉、AIっぽさ）を見せる。結果は項目ごとに ✓／！。足りない所があれば、チェック後にポコッと出るウィンドウで一問一答（最大3問）で聞き返す（あとで答えることもでき、記事の画面のいちばん上に「AIから質問が◯つ届いています」を出し続ける。チェック前は同じ場所に「AIOのチェックを実施」）。「記事に反映する」で答えを書き込んだ新しい版を作る。終わったら「チェック済み」。記事を直したら、もう一度チェックできる
- コタムのコメントがあれば、記事の画面の上に「コタムからコメントが届いています」と最新のコメントを出す
- 「タイトルをコピー」「本文をコピー」「HTMLをコピー」。AIOのチェックがまだなら、チェックをすすめる
- 「公開済みにする」（公開URL入力）

コタムが開いた場合：同じ画面で、AIOのチェックの結果とAIとのやり取り（これまでのチェックも）を読み、「コメントを残す」でお客様にコメントを送れる。承認と修正依頼はない（2026-11-02）。

## 画面状態

すべての画面で次の状態を用意する。

| 状態 | 表示 |
|---|---|
| 空 | 次にやることを1文で案内 |
| 読み込み中 | スケルトン表示 |
| 生成中 | 進行表示と「この画面を閉じても続きます」 |
| 生成失敗 | 入力は保持したまま、理由と「もう一度試す」 |
| 利用上限到達 | 「今月の生成回数の上限に達しました。コタムにご相談ください」 |
| 生成を実行中（busy） | 「同じ会社で文章を作っている途中です。終わってからもう一度お試しください」 |
| 予算に達して停止（budget_exceeded） | 「今月は新しい文章を作れなくなっています。コタムにご連絡ください」 |
| 保存失敗 | 未保存であることを明示し、再試行。保存成功前に「保存済み」を表示しない |
| 編集競合 | 「別の画面で更新されました」と、最新版を開くか自分の内容を別版で残すかの選択 |
| セッション切れ | 再ログイン後に同じ画面と入力へ戻る |
| 権限なし | 「この記事を表示する権限がありません」 |
