# UI：画面・文言・状態

## 共通ルール

- 専門用語を減らし、次の操作をひとつずつ示す。主導線のボタン文言は「今月の記事を書く」
- 本文16px以上、すべての入力欄にラベル、キーボードだけで操作可能、十分なコントラスト（WCAG AA相当）
- 色とロゴは仮置き
- 幅375pxと1280pxで確認。長い会社名・見出しでも横スクロールやボタン欠けを起こさない
- 画面試作の段階では、生成結果は「サンプル（AIは未接続）」と画面上に明示する

| ID | 画面 | 利用者 | パス案 |

## S1 ホーム

- 上部：会社名、今月の指導方針（顧客向け指導メモの要約）
- 中央：「今月の記事を書く」（主ボタン）、「書きかけの記事を続ける」（最新の作成中記事がある場合のみ）
- 下部：記事一覧。列はテーマ、状態、更新日、コタムのコメント有無
- 数値ダッシュボードを主役にしない

## S2 テーマを選ぶ

- コタムが登録した今月のテーマをカード表示。各カードに「誰の悩みに答えるか」「伝えたい内容」
- 「自分でテーマを決める」カード（タイトルと悩みを入力）
- 会社プロフィールまたは指導メモが未登録なら「コタムが準備中です」と表示し、記事作成へ進ませない（コタムには初期設定へ案内）

## S3 質問に答える

- 4〜6問を1問ずつ表示。進捗（例：2／5）、戻る、下書き保存を常時表示
- 各質問に記入例と「まだ分からない」ボタン
- 質問例：
  1. お客様から何を相談されましたか
  2. 実際にはどう対応しましたか
  3. 結果はどうなりましたか（数値があれば）
  4. 注意点や、よくある誤解はありますか
  5. この記事を読んだ人にしてほしいこと（問い合わせ等）
- 回答が具体例に欠ける場合、生成前に追加質問を1〜2問出す
- 全問回答後「見出し案を作る」

## S4 記事を整える

PC：本文を主領域、右に補助領域（タブ：質問回答／指導方針／要確認箇所／コメント）。スマートフォン：上部タブで本文と補助領域を切り替え。

主領域：
- タイトル候補から選択、または直接編集
- 見出しと本文を編集
- 範囲を選んで「短くする」「伝わりやすくする」→ 変更案を差分表示 →「採用」「やめる」
- 「もう一度作る」は新しい版を作る（元の版は残る）
- 版の履歴から以前の版を復元

要確認箇所タブ：
- 数値・実績・価格・顧客名などを一覧表示。該当箇所へジャンプ
- 各項目に「確認した」「修正した」「削除した」。未確認が残っていれば確認依頼・書き出し時に件数を警告（止めはしない）

操作ボタン：
- 「コタムに確認を頼む」（確認依頼が必須の会社では、承認前の公開済み登録ボタンを無効化）
- 「タイトルをコピー」「本文をコピー」「HTMLをコピー」。未承認なら「下書きです」と表示
- 「公開済みにする」（公開URL入力）

コタムが開いた場合：同じ画面で、補助領域に「コメントする」「修正を依頼」「承認する」を表示。

## S5 コタム管理画面

- 担当企業一覧（企業名、確認待ち件数、今月の書き出し数、利用回数）
- 確認待ち記事の一覧（依頼日の古い順）
- S5a：会社プロフィール、顧客向け指導メモ、内部メモ（「AIには渡しません」と表示）、テーマ、過去記事、確認依頼の必須・任意設定
- 管理者権限はサーバー側で確認する（画面を隠すだけにしない）

## 画面状態

すべての画面で次の状態を用意する。

| 状態 | 表示 |
|---|---|
| 空 | 次にやることを1文で案内 |
| 読み込み中 | スケルトン表示 |
| 生成中 | 進行表示と「この画面を閉じても続きます」 |
| 生成失敗 | 入力は保持したまま、理由と「もう一度試す」 |
| 利用上限到達 | 「今月の生成回数の上限に達しました。コタムにご相談ください」 |
| 生成を実行中（busy） | 「同じ会社で文章を作っている途中です。終わってからもう一度お試しください」 |
| 予算に達して停止（budget_exceeded） | 「今月は新しい文章を作れなくなっています。コタムにご連絡ください」 |
| 保存失敗 | 未保存であることを明示し、再試行。保存成功前に「保存済み」を表示しない |
| 編集競合 | 「別の画面で更新されました」と、最新版を開くか自分の内容を別版で残すかの選択 |
| セッション切れ | 再ログイン後に同じ画面と入力へ戻る |
| 権限なし | 「この記事を表示する権限がありません」 |

## 状態ラベル（顧客向け文言）

| 内部値 | 表示 |
|---|---|
| drafting | 作成中 |
| in_review | 確認待ち |
| changes_requested | 修正依頼あり |
| approved | 承認済み |
| published | 公開済み |

## ユーザーテスト

初回利用者が説明なしで、テーマ選択から書き出しまで進めるかを顧客1〜2名で試す。
